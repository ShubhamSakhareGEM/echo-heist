# Echo Heist

Echo Heist is a 2D top-down stealth game developed in Unity for
ITCS-5236: AI in Gaming.

The player must infiltrate a secure facility, steal a protected
artifact, and escape while avoiding a team of adaptive AI security
guards.

## Core AI Concept

The game focuses on an adaptive multi-agent guard system.

Planned AI systems include:

- Finite State Machines
- Field-of-view and line-of-sight perception
- A* pathfinding
- Shared agent memory
- Tactical heat maps
- Utility-based decision making
- Coordinated multi-agent behavior
- Dynamic difficulty adjustment
- Long-term episodic memory / RAG
- High-level AI strategy planning

## Gameplay

1. Enter the facility
2. Avoid or distract guards
3. Steal the artifact
4. Reach an escape point
5. Replay against guards that adapt to previous player behavior
